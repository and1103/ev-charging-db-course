# 用户会员及车队

## 用例分析

参与者为车主、运营管理员、车队管理员。主要用例包括注册、绑车、用券、余额、发票申请及车队月账单。

## 鲁棒关系

个人中心接口 → 会员控制 → 用户、车辆与绑定；领券和用券接口 → 优惠控制 → 活动、券和核销；账户查询 → 账户管理 → 余额和流水。

## 局部关系与规范化

账户 1:N 绑定，车辆 1:N 历史绑定；活动 1:N 券；券与订单各最多一条核销；车队 1:N 卡。余额由事务和流水共同维护。

同目录 SQL 为本模块物理模型和查询实现。部署后运行根目录 dictionary.py 可按模块导出实际字段、类型、默认值、约束与索引。

## 接口协作

A、B 读取车辆归属和参数；B 与优惠、钱包服务共享订单事务；C 验证运维权限；E 对齐运营商权限及发票职责。
