# 早期环境验收记录（历史背景）

本文件正文是部署前的早期状态，后续已完成MySQL8.4部署和多轮真实测试。它不表示第二版仍未部署；当前执行方法见[04测试说明](../../../../04_测试与验收/README.md)，历史后端结果见执行记录。

目标环境为 MySQL 8.4、InnoDB 和 PyMySQL。迁移后已静态核对 Python 语法、SQL 脚本分句、部署文件顺序与查询数量。当前可见的 MySQL 5.1 客户端无法启动，8.4 便携包下载未完成。数据库部署、接口联调、并发与恢复仍待在 MySQL 8.4 上运行。
