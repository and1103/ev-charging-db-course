# 初始化与样例

这里提供课程合成数据，支撑订单、资金、工单和结算的可解释演示。只在准备好的新空业务库第一次初始化时使用，日常启动网页不需要执行。

| 顺序 | 文件 | 作用与前提 |
|---|---|---|
| 1 | [seed.sql](seed.sql) | 基础20组样例及admin/settlement账号、费率、订单、活动、告警、排队等；由部署器的`--demo`调用 |
| 2 | [seed_extended.py](seed_extended.py) | 在基础样例上补20组退款、复核、完整外账、双方确认及蓝红票闭环 |
| 3 | [seed_fleet.py](seed_fleet.py) | 补20组企业信用计费及期初钱包案例；企业应付与现金付款分开记录 |

`seed.sql`内的`demo-pending`是临时口令占位值。部署器会使用运行配置里的演示密码生成随机盐哈希并写入，再记录`seed.sql`版本。**不要把单独执行seed.sql当作完整账号初始化**，否则账号口令没有完成这一步处理。

三个样例阶段使用固定迁移标记`seed.sql`、`seed_extended.py`、`seed_fleet.py`避免成功加载后再次插入；它们不是面向任意数据库的增量业务导入器。扩展脚本依赖基础样例既定的用户/设备/业务编号，顺序不能颠倒。

## 在新库中的运行方式

先按[部署工具说明](../部署工具/README.md)明确新空库并准备管理员连接。在第二版根目录执行：

```powershell
.\01_平台工程\.venv\Scripts\python.exe .\02_数据库脚本\部署工具\deploy_local.py --demo
.\01_平台工程\.venv\Scripts\python.exe .\02_数据库脚本\初始化与样例\seed_extended.py
.\01_平台工程\.venv\Scripts\python.exe .\02_数据库脚本\初始化与样例\seed_fleet.py
```

这些入口在真正执行main时读取本机运行配置，保留管理员已经显式设置的`CHARGE_ADMIN_DSN`。管理连接必须指向你明确准备的新库；应用账户的现有DSN不能替代建库管理员。

历史样例主要在2026年11月，所有时刻按北京时间解释。订单1是跨时段计费讲解案例；“近30天”“最近一天”等查询随当前日期变化，出现空集时应补场景和固定基准时间，不能擅自修改历史样例日期以制造实时数据。

本次第二版整理仅移动文件和修正路径，不会再次加载这些样例或改变现有数据库。
