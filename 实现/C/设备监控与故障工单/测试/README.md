# C 模块回归测试

在仓库根目录打开 MySQL 客户端，在已执行 `07_monitor.sql` 的 MySQL 8.4 课程数据库中运行：

```sql
SOURCE 实现/C/设备监控与故障工单/测试/C_regression_monitor.sql;
SOURCE 实现/C/设备监控与故障工单/测试/regression_alarm_scope.sql;
```

两组脚本分别验证：

1. 工单不能跳过接单或到场，未修复、样本过旧、来源枪未恢复时不能关闭告警。
2. 维修后的三条正常遥测满足时间窗口、心跳新鲜且来源枪状态正常时，才允许恢复。
3. 同一枪同一故障码重复上报时复用活动告警，不同枪生成不同告警。
4. 跨桩枪不能作为告警来源，整桩告警与枪级告警可以并存。

脚本使用临时夹具，并在正常或异常结束时回滚业务数据。创建和删除测试存储过程属于 DDL，因此自动递增编号可能出现空号。
