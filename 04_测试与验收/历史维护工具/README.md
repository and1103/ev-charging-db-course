# 历史维护工具：阅读与追溯

本目录不是正常启动、默认验证或新库安装入口。

| 文件 | 原用途 | 使用边界 |
|---|---|---|
| finalize_schema.py | 旧库钱包幂等字段、枪级告警字段及例程增量修复 | 当前正式DDL已包含这些变化；不要在新库重复执行 |
| refresh_funding.py | 定向替换5个资金/额度相关存储程序 | 会DROP/CREATE例程，需管理员评审；普通运行不要执行 |
| generate_acceptance.py | 汇总初版12组回归、旧空库与恢复证据 | 依赖初版证据布局，仅供阅读，不用它生成第二版验收结论 |
| tests_runner.py | 旧12组测试入口 | 现为薄兼容入口，默认转发第二版api组；旧12组映射由主说明追溯 |

原测试/升级输出保存为带日期的历史证据。第二版的唯一现行验证实现为上级`run_checks.py`，它不会自动执行本目录的修改数据库工具。
