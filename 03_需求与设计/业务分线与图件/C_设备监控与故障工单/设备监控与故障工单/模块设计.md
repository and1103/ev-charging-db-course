# 设备监控与工单

## 用例分析

参与者为运维人员、运营管理员、设备模拟器。主要用例包括批量上报、告警升级、派单、维修及恢复。

## 鲁棒关系

设备接入 → 运行判定 → 采集和告警；工单接口 → 状态流转 → 工单与备件；单次调度入口 → 超时检查 → 告警通知。

## 局部关系与规范化

桩 1:N 采集、告警；告警 1:N 工单；工单 1:N 备件条目。采集键为桩与采样时间，告警响应时间由触发时规则快照决定。

本目录保存模块设计与PNG。物理模型和查询实现统一位于[对应SQL目录](../../../../02_数据库脚本/C_设备监控与故障工单)；[结构导出](../../../数据库结构导出)提供实际字段、约束与索引，维护导出入口见[测试维护工具](../../../../04_测试与验收/维护工具)。

## 接口协作

A 联调资产状态和排队撤销；B 联调断连暂核；D 验证运维权限；E 共享联调订单与恢复核对数据。
