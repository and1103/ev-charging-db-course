# 本地DOM开发检查

这里保存测试源码和npm锁文件，不保存旧版node_modules或旧业务快照。首次需要运行`npm ci`安装开发依赖，正式网页运行不需要npm。

从第二版根目录运行：

```powershell
npm ci --prefix "04_测试与验收/DOM模块测试" --no-audit --no-fund
.\运行验证.cmd dom
```

统一入口先执行`capture_api.py`，用Flask进程内测试客户端采集当前合成数据库的6角色GET响应；再执行`render_modules.mjs`。快照和结果都写入本次验证目录，由`CHARGE_TEST_OUTPUT`在两个步骤间共享，源目录不会不断堆积旧快照。

jsdom使用默认的HTML脚本禁用模式，只显式导入本地业务模块。fetch只读取本地快照，拒绝未收集请求和所有写请求，不访问网页、不启动浏览器。

预期覆盖52个真实响应渲染、7个明确标记的合成订单状态分支及7个入口场景。结果记录实际用例数和各源码SHA-256，不固定以历史66条记录冒充本轮通过。它不证明真实浏览器布局、原生交互、CSP行为或端到端业务写入。
