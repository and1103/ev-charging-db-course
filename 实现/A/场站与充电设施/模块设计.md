# 场站设施及排队

## 用例分析

参与者为平台管理员、车主、设备模拟器。主要用例包括登记验收、查询设备、取号、叫号、超时顺延。

## 鲁棒关系

场站页面 → 资产查询 → 场站、桩、枪；车主取号接口 → 叫号分配 → 排队、叫号、枪保留；设备事件 → 状态更新 → 待办与保留。

## 局部关系与规范化

运营商 1:N 场站 1:N 桩 1:N 枪；车辆 1:N 排队 1:N 叫号，叫号 1:1 保留。枪号决定枪型、接口和功率；不在排队中复制车辆参数。

同目录 SQL 为本模块物理模型和查询实现。部署后运行根目录 dictionary.py 可按模块导出实际字段、类型、默认值、约束与索引。

## 接口协作

A 提供枪锁和保留资格；B 使用同一枪记录开单；C 在离线时触发撤销；D 提供车辆绑定与兼容属性。
