# 设备监控与工单

## 用例分析

参与者为运维人员、运营管理员、设备模拟器。主要用例包括批量上报、告警升级、派单、维修及恢复。

## 鲁棒关系

设备接入 → 运行判定 → 采集和告警；工单接口 → 状态流转 → 工单与备件；定时入口 → 超时检查 → 告警通知。

## 局部关系与规范化

桩 1:N 采集、告警；告警 1:N 工单；工单 1:N 备件条目。采集键为桩与采样时间，告警响应时间由触发时规则快照决定。

同目录 SQL 为本模块物理模型和查询实现。部署后运行根目录 dictionary.py 可按模块导出实际字段、类型、默认值、约束与索引。

## 接口协作

A 联调资产状态和排队撤销；B 联调断连暂核；D 验证运维权限；E 共享联调订单与恢复核对数据。
