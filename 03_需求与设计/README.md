# 03 需求与设计：从业务理解到数据库模型

本板块面向第一次接手项目的组员、报告编写者及模型维护者。整合日期为2026-11-16；业务结构沿用已验证的44表设计。这里保存分析说明、模型、字段字典和PNG，运行程序在01，唯一SQL源在02。

## 推荐阅读顺序

1. [需求分析与设计阅读指南](需求分析与设计阅读指南.md)：沿需求→E-R→关系模式→物理设计→实施→持久层理解项目。
2. [功能与任务对应清单](功能与任务对应清单.md)：查每项功能在哪里操作、调用哪个接口、由谁负责以及怎样核验。
3. [图件索引](图件索引.md)：先读全局E-R/UML，再选本人业务线的局部E-R、用例、鲁棒及完整字段UML。
4. [全局模型清单](模型与数据字典/A/场站与充电设施/全局模型.md)：查44个实体及全部关系。
5. [数据库设计与数据字典](模型与数据字典/数据库设计与数据字典.md)：查320字段、主外键、默认值、CHECK、索引及逐表范式说明。
6. 对照[02数据库脚本](../02_数据库脚本)与[04测试入口](../04_测试与验收/README.md)，把说明与真实实现、结果对上。

## 每个目录做什么

| 目录或文件 | 用途 | 是否运行程序时必需 |
|---|---|---|
| 业务分线与图件 | A—E各线的模块说明及34张正式PNG；A包含设施、排队两个子分区 | 否，供阅读、报告与答辩 |
| 模型与数据字典 | 全局实体/关系清单、完整字典、只含结构的元数据快照与离线生成器 | 否 |
| 数据库结构导出 | 按业务模块保存的字段、约束、索引CSV，来源于原实库导出 | 否；结构变化后应重新导出 |
| 图件维护工具 | DDL解析、模型核对、内嵌布局清单和可选PNG渲染工具 | 否；仅模型维护者使用 |
| 图件索引.md | 所有正式图件的入口、图例与使用范围 | 否 |
