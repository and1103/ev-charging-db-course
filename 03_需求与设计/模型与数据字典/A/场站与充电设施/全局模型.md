# 全局模型与图码对应

本文件由 `实现/过程文件/图件工具/生成图件.py` 从当前业务 DDL 重新生成。旧版只展示主链的 Mermaid 图已由完整图件及下列实体、关系清单替代。

本版包含 44 个业务实体、320 个表字段、75 条物理外键关系和 4 条逻辑关联。部署跟踪表不属于业务概念模型。

全局图：[UML PNG](../../../业务分线与图件/A_场站设施与排队/场站与充电设施/全局UML类图.png) · [Chen E-R PNG](../../../业务分线与图件/A_场站设施与排队/场站与充电设施/全局ER图.png)。完整字段分区图与全部分析图见 [图件索引](../../../图件索引.md)。

全局概念图以业务实体及基数表达关系；主标识下划线。UML 为持久化数据类模型，属性保留类型、主外键及必填性。历史金额及计费快照属于历史事实，不能由当前费率或当前设备归属回推。

## 实体分区

| 分区 | 实体 |
|---|---|
| 场站与充电设施 | 运营商（`operator`）、场站（`station`）、充电桩（`charger`）、充电枪（`connector`）、设备状态历史（`asset_history`）、设备验收与变更申请（`asset_request`） |
| 充电估算与到站排队 | 排队记录（`queue_entry`）、叫号记录（`queue_call`）、充电枪保留（`gun_hold`） |
| 充电订单与计费 | 计费规则版本（`tariff`）、峰平谷费率时段（`tariff_band`）、充电订单（`charge_order`）、枪级电表读数（`meter_sample`）、分段费用明细（`fee_detail`）、异常订单复核（`order_review`）、支付记录（`payment`）、退款记录（`refund`） |
| 设备监控与故障工单 | 运行遥测（`telemetry`）、告警规则（`alarm_rule`）、告警（`alarm`）、维修工单（`work_order`）、工单备件（`work_part`）、告警通知（`alarm_notice`） |
| 用户与会员运营 | 登录账户及会员（`account`）、车辆（`vehicle`）、车辆归属历史（`vehicle_binding`）、企业车队（`fleet`）、车队卡及额度（`fleet_card`）、优惠活动（`campaign`）、已发优惠券（`coupon`）、账户余额流水（`wallet_entry`）、优惠券核销（`redemption`）、用户开票申请（`consumer_invoice_request`）、用户报障及评价（`driver_feedback`） |
| 结算与对账 | 运营商结算单（`settlement`）、结算订单快照（`settlement_item`）、对账导入批次（`settlement_import`）、运营商账单明细（`external_bill`）、对账差异（`recon_diff`）、差异双方确认（`diff_confirmation`）、结算双方确认（`settlement_confirmation`）、结算调整（`settlement_adjustment`）、结算发票及红冲（`settlement_invoice`）、用户发票及红冲（`consumer_invoice`） |
