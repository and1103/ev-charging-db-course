# 维护工具：单次调度扫描

[scheduler.py](scheduler.py)用于管理员明确执行一次维护扫描。它复用数据库存储程序，在一个调用方事务中依次：

1. `scan_offline()`检查设备心跳和离线。
2. `escalate_alarms(SYSDATE(6))`检查未响应告警是否达到升级时限。
3. 遍历场站并调用`dispatch_station(id)`，处理排队分配及相关留枪状态。

## 如何运行

在第二版根目录执行：

```powershell
.\01_平台工程\.venv\Scripts\python.exe .\01_平台工程\维护工具\scheduler.py
```

真正执行main时会读取当前Windows用户的本机受保护配置，使用`CHARGE_DATABASE_URL`连接应用数据库。需要相关表查询、业务写入和存储程序EXECUTE权限；口令不作为命令行参数传递。

这个命令**会改变符合条件的业务状态**，不是只读健康检查。不要仅为查看源码、导入模块或检查路径而调用main；普通import现已不会运行扫描或访问数据库。

网页管理员的“单次调度扫描”提供相同维护目的。手动运行一次不表示已安装周期任务，启动Flask也不会自动按间隔执行此脚本。后续如要使用Windows计划任务或其他调度器，应先明确周期、运行账号、日志和失败处理，再单独实施与验证；本次目录整理没有新增计划任务。

设备恢复仍需满足工单、修复后新鲜正常样本及观察条件。扫描入口不提供绕过恢复约束、改系统时间或直接修正费用的能力。
