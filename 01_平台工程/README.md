# 01 平台工程：网页、后端与持久层

本板块是唯一运行源码。Python、Flask、SQLAlchemy和PyMySQL服务于同一MySQL课设库；Jinja提供HTML骨架，模块化JavaScript调用同源接口，CSS和图标均在本机，不需npm构建网页。

## 1. 文件分工

| 文件或目录 | 作用 |
|---|---|
| app.py | 五条业务线的核心JSON接口、参数校验、角色/归属校验、公共事务与错误转换 |
| web_ui.py | 登录/工作台页面路由、全角色会话、CSRF/来源保护、权限过滤的页面读模型 |
| repositories.py | 运营商/站/桩/枪参数化CRUD与分页；事务由调用方统一管理 |
| auth.py | 随机盐scrypt密码哈希、恒时比较、PII加密及掩码 |
| local_runtime.py | 读取本用户DPAPI配置；受限执行项目内脚本；配置新库或连接已有库 |
| web_launcher.py | 检查依赖与数据库、识别本版实例、隐藏启动、按完整项目路径安全停止 |
| deploy.py | DDL解析和部署编排，读取02板块唯一SQL；不是日常启动时自动执行的建库动作 |
| project_paths.py | 全工程路径的唯一配置，避免工具写回旧目录 |
| templates/ | 登录页和工作台HTML骨架 |
| static/js/ | 公共请求/表单/表格、角色导航、A设施、B订单、C/E工单结算、D会员车队 |
| static/css/ | 桌面工作台及窄屏适配样式 |
| 维护工具/scheduler.py | 单次扫描离线、超时升级和排队调度；仅显式执行，不因import自动写库 |
| .local/ | 本机私有配置和已有密码资料，分享源码时排除 |
| .venv/ | 本工程重新建立的Python环境，迁移到别的电脑应按锁文件重建 |

SQL位于[02_数据库脚本](../02_数据库脚本/README.md)，测试位于[04_测试与验收](../04_测试与验收/README.md)，不会在运行树里再保存另一套副本。

## 2. 启动、停止与登录

返回项目根，双击“启动平台.cmd”。结束时双击“停止平台.cmd”，它核对本工程进程和5000端口；不会按过期PID或Python名称结束其他项目。

| 角色 | 合成账号 | 页面范围 |
|---|---|---|
| 管理员 | admin | 设施、订单、会员、工单、车队、结算、票据、模拟控制 |
| 车主 | driver1 | 场站/排队、本人订单、车辆/钱包/优惠 |
| 维修 | tech1 | 本人范围告警与工单 |
| 平台结算 | settlement | 订单复核、结算、消费开票 |
| 运营商 | operator1 | 本运营商结算、差异意见和独立签字 |
| 车队负责人 | fleet1 | 本企业卡、额度、订单与月账单 |

本机已有的密码文件在.local/密码.txt。其内容不放在公共文档；原先用户要求删除的查看/复制密码工具没有带回。本机加密配置是`.local/runtime.dpapi`。其他电脑的密码由其数据库管理员提供，不能假设所有环境相同。

新环境configure会生成自己的演示密码，不自动生成明文密码文件。首次初始化后，可在第二版根目录用已有内置命令仅在本机查看：

```powershell
.\01_平台工程\.venv\Scripts\python.exe .\01_平台工程\local_runtime.py demo-login
```

输出`Demo password:`后为该环境的密码。连接已有库时应使用该库负责人提供的现有演示密码；不复制其他人的本机密码文件或把值写入公共文档。

角色由真实登录会话决定。普通标签页共享Cookie，演示双边签字时要退出换号或使用独立浏览器配置；不能靠界面角色下拉框改变授权。

## 3. 三条主要演示路线

**车主充电链**：核验账号与车辆→钱包准备→场站看枪→估价/取号→叫号留枪或可用枪开单→管理员模拟原始读数→停止请求/结束核价→优惠→付款→反馈/开票申请。新账号需要管理员核验。设备心跳仅3分钟有效，过期时如实不可用。

**运维链**：管理员模拟明确的桩/枪来源告警→派给本场站维修人员→接单→到场→修复→关闭→修复后的正常采样与观察→按规则恢复。关闭工单不等于马上满足恢复条件。

**财务链**：生成账期快照→完整CSV预览/导入→查看漏单/多单/金额差异→双方分别给出意见→平台/运营商分别签字→消费或结算蓝票/红冲。只有草稿可重置外账批次，已确认账单保持冻结。

固定订单1可只读讲解100→104→110电表、4/6kWh分段、11.40原价、2.00优惠和4.00+5.40两笔付款。新订单用其实际时间/费率和服务端金额，不预设必须等于历史案例。

模拟输入集中在管理员控制台。起始读数使用订单原始started_at微秒时刻，常规读数使用服务器时刻；结束时取有效最新采样。桩级遥测和枪级订单读数分开展示，不伪造实时SOC。

## 4. 本机配置与其他成员

### 当前电脑

复制来的DPAPI文件仅用于当前Windows用户，启动时读取，不改数据库账户或口令。后台默认只监听127.0.0.1:5000。

### 连接已存在的课设库

在第二版根目录终端执行：

```powershell
.\01_平台工程\.venv\Scripts\python.exe .\01_平台工程\local_runtime.py connect-existing
```

本机不存在运行配置时，按提示输入获得授权的应用数据库账号/密码、现有PII密钥及现有演示密码。目标为3307端口的charge_course_20261114。工具只读验证登录密码，并优先用已有手机密文、其次用车牌密文核验密钥。若两类密文均为空，只能校验密钥格式并提示，仍须使用负责人交接的同一PII密钥。成功后以Windows DPAPI新建本机配置，不修改库中数据，也不覆盖已有配置。PII密钥应由负责人通过授权方式交接，不放进报告或公共源码。

### 全新数据库初始化

先安装MySQL 8.4并准备3307端口，再运行根目录“安装环境.cmd”。确认该服务器不存在目标课设库后，在第二版根目录运行：

```powershell
.\01_平台工程\.venv\Scripts\python.exe .\01_平台工程\local_runtime.py configure
```

按提示输入管理员密码。这个动作创建新库和应用账号，库已存在就拒绝；连接已有库应选择上面的connect-existing，两个流程按实际环境二选一。新库创建后，管理员再按[数据库部署说明](../02_数据库脚本/README.md)提供仅本次进程有效的管理员连接，执行九步DDL和基础、扩展、车队三组样例，最后启动网页。配置完成本身不表示44张表已经建好。

建库、空库验证、恢复演练均不可覆盖已有主课设库。

## 5. 修改规则和现有边界

网页金额、状态和权限均以服务端为准；收费和分成规则不在浏览器另算一套。DB操作采用参数化值和受控表名；公共事务失败即回滚。新图或表变更后，要同步03模型/字典、02 SQL和04测试。

当前部分SQL仍集中于app.py，后续可继续按业务拆Service/Repository。费率配置网页只读，查询窗口有数量限制，自动轮询/周期任务尚未部署。详见03功能清单和04验收范围。
