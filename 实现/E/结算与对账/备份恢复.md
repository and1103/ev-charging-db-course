# MySQL 备份恢复演练

在独立 MySQL 8.4 实验实例上执行。用 mysqldump 备份 InnoDB 数据及存储程序、触发器。通过 mysql 客户端在空库执行备份文件，记录恢复时间并核对订单、支付、结算、差异和发票。

```powershell
mysqldump --single-transaction --routines --triggers --set-gtid-purged=OFF -u backup -p --result-file=charge-demo.sql charge
mysql -u restore -p charge_restore
```

登录客户端后执行 `SOURCE charge-demo.sql`。恢复账号须有在目标库创建所含对象的权限。备份中的 DEFINER 如引用原实例账号，恢复前由管理员检查并处理对应账号与权限。

时间点恢复使用定期全量备份与持续保留 binlog。记录备份对应的 binlog 文件及位置，在独立实例恢复全量备份后，用 mysqlbinlog 从该位置重放到目标时间或位置。记录目标恢复点、实际恢复点、耗时及金额核对结果。
