# 订单计费及支付

## 用例分析

参与者为车主、客服、支付和读数模拟器。主要用例包括扫码启动、结束分段计费、支付、退款和人工复核。

## 鲁棒关系

扫码入口 → 开单控制 → 订单和枪保留；读数入口 → 核价控制 → 费率和费用明细；付款入口 → 入账控制 → 订单、支付和流水。

## 局部关系与规范化

订单 1:N 电表读数、费用明细及支付；支付 1:N 退款。费率版本和起始分钟决定时段属性，支付渠道与流水组合唯一。

同目录 SQL 为本模块物理模型和查询实现。部署后运行根目录 dictionary.py 可按模块导出实际字段、类型、默认值、约束与索引。

## 接口协作

A 提供枪可用性；C 提供设备异常及最后读数；D 核销和钱包与订单事务衔接；E 消费核价和支付快照。
