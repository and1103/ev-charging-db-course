首次使用时运行根目录的 `安装环境.cmd`，按平台工程说明创建或连接本机课设库，然后运行 `启动平台.cmd`。网页访问 `http://127.0.0.1:5000/ui/`，使用后运行 `停止平台.cmd`。

本机连接配置、密码、依赖目录、数据库转储、运行日志和历史草稿由本地保存。[第二版整合与验收说明](过程文件/本次整合/第二版整合与验收说明.md)记录已有测试结果和适用范围。
